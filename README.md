Commands:
- every menu has its commands and functions which are written in the menu (for example q for quitting etc.), that part is pretty much straight-forward
- there are some commands introduced to make hacking feel realistic instead of the game's simple R2 and/or Square (PS4 controls for example)
- this is not a game mod or in any way a real hack tool...
